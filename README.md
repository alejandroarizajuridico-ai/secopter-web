# S.E.C.O.P.T.E.R. 🚁
**Sistema Estratégico de Captura de Oportunidades Públicas y Tendencias Estatales Regionales**

## 🚀 Características Principales
* **Motor Híbrido Multifuente:** Extracción en tiempo real y en paralelo de las bases de datos abiertas del Estado (SECOP I y SECOP II) mediante sesiones HTTP persistentes y consultas SQL estructuradas (LIKE).
* **Filtros Especializados:** Segmentación por tipo de contrato (incluyendo subcategorías de obra y jurídicas), modalidades, departamentos y umbrales financieros.
* **Filtro Anti-Ruido:** Sistema inteligente de palabras a excluir para depurar alertas irrelevantes.
* **Exportación y Transmisión:** Generación automatizada de reportes en formato Excel (.xlsx) con opciones de descarga directa y envío automatizado vía correo electrónico cifrado.
